      NovaStar 유지보수 장점

      장애 대응 표준화

      증상별 점검 순서를 고정해 담당자 경험 차이로 인한 누락을 줄입니다.

      상태 가시화

      캐비닛, DATA 포트, 전원, 온도 상태를 한 화면에서 빠르게 판단합니다.

      현장 공유

      직원이 같은 페이지에서 테스트하고 동일한 보고문구로 상황을 공유합니다.

      DB 일원화

      LED Viewer의 조달 DB는 Realtime Database 기준으로 여러 클라이언트가 동일하게 유지됩니다.

      예방정비 기반

      반복 장애 유형과 조치 기록을 축적해 포트·수신카드·전원 취약 구간을 찾습니다.

      안전한 운영

      기본은 점검/관제 중심으로 두고, 실제 제어는 승인 절차 뒤 수행하는 구조에 맞춥니다.

      기술적 구성 포인트

      COEX / VMP 연동 대비

      컨트롤러 제어권, 장비 응답, 화면 구성 충돌을 구분해 점검할 수 있게 구성했습니다.

      SNMP / Trap 알람

      장비 상태 알람을 유지보수 흐름에 연결해 통신·전원·온도 이상을 빠르게 분류합니다.

      DATA Chain 분석

      포트별 캐비닛 체인을 시각화해 어느 지점에서 신호가 끊기는지 추적합니다.

      5V / 전원 품질 점검

      수신카드·모듈 불안정의 주요 원인인 5V 저하와 부하 편차를 우선 점검 항목으로 둡니다.

      열 적체 판단

      후면 공간, 팬, SMPS 주변 온도 문제를 장애 유형으로 분리해 조치 방향을 제시합니다.

      Realtime DB 동기화

      GitHub Pages 화면은 정적 배포하고, 제품 DB는 Firebase Realtime Database로 공유합니다.

      유지보수 상태 대시보드 직원 테스트용
